> [!IMPORTANT]
> **Notice**
>
> 这个仓库最初是一个围绕 *The Economist* 的个人阅读和英语学习项目，相关笔记希望帮助英语学习者，尤其是备考学生，更好地接触和理解严肃长文阅读。
>
> 这个公开仓库目前不再以任何格式托管 *The Economist* 内容文件。
>
> 这次调整源于某第三方分发商多次提出与分发相关的投诉。此后，本仓库将仅作为阅读笔记、期刊索引和博客解析项目继续公开。

---

## 📌 当前范围

这个仓库目前围绕公开阅读笔记、期刊参考和相关解析链接展开。

它可以包含：

- 仓库公告
- 阅读笔记和期刊参考
- 博客解析链接
- 中英文公开说明

## 🚫 不支持的内容

以下内容不会放在这个公开分支中：

| 内容 | 状态 |
| --- | --- |
| PDF 文件 | 不托管 |
| EPUB 文件 | 不托管 |
| MOBI 文件 | 不托管 |
| AZW3 文件 | 不托管 |
| 封面图片和提取出的 JPG 文件 | 不托管 |
